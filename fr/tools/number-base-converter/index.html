About the

Le convertisseur de base numérique convertit une valeur entre binaire, octal, décimal et hexadécimal, et affiche les quatre à la fois afin que vous puissiez lire ce dont vous avez besoin. Laissez la base sur Auto et elle lit les préfixes 0x, 0b et 0o pour vous, ce qui signifie que vous pouvez coller 0xFF directement à partir du code source et obtenir 255, 1111, 1111 et 377 sans rien définir. Les valeurs sont traitées comme des entiers de précision arbitraire, de sorte qu'une valeur de 64 bits est convertie exactement au lieu de perdre ses bits supérieurs.

Where people use the

  • Lecture d'une valeur hexadécimale à partir du code source sous forme décimale et binaire.
  • Vérifier quels bits sont définis dans un indicateur ou un masque.
  • Conversion d'une valeur de couleur entre les canaux hexadécimaux et décimaux.
  • Vérifier un littéral binaire dans un fichier de configuration avant de le valider.

How to use the

  1. 1

    Entrez une valeur

    Tapez un nombre dans n'importe quelle base : 255, 0xFF, 0b11111111 ou 0o377. Les espaces et les traits de soulignement sont ignorés.

  2. 2

    Laissez la base sur Auto, ou forcez-en une

    Auto lit le préfixe et revient à faire correspondre les chiffres. Choisissez Binaire, Octal, Décimal ou Hex pour forcer une interprétation.

  3. 3

    Lisez les quatre

    Décimal, hexadécimal, binaire et octal sont affichés ensemble. Le binaire est regroupé par quatre pour le rendre lisible.

  4. 4

    Copiez ce dont vous avez besoin

    Chaque ligne possède son propre bouton de copie et le résultat combiné peut être copié en une seule fois.

Conseils et bonnes pratiques

  • Collez les valeurs 0x directement à partir du code ; le préfixe est lu automatiquement.
  • La sortie binaire est regroupée par quatre pour correspondre à la façon dont les quartets sont mappés aux chiffres hexadécimaux.
  • Forcer une base lorsqu'un nombre nu peut être lu de deux manières, comme 10.

Questions fréquemment posées

Que signifient les préfixes 0x, 0b et 0o ?

Ils marquent la base : 0x pour hexadécimal, 0b pour binaire et 0o pour octal. Ce sont les conventions utilisées par C, JavaScript, Python et la plupart des autres langages, le code peut donc être collé directement.

Pourquoi ma valeur binaire est-elle rejetée lorsque je force la base 2 ?

Parce qu'il contient des caractères autres que 0 et 1. Une valeur avec des espaces convient, mais une valeur avec un préfixe 0b ne l'est pas, car le préfixe n'est pas un chiffre binaire.

Peut-il gérer de très grands nombres ?

Oui. Les valeurs sont traitées comme des entiers de précision arbitraire, donc une valeur de 64 bits ou plus est convertie exactement. Seuls les nombres entiers sont pris en charge.

Gère-t-il les nombres négatifs ?

Oui. Un signe moins est conservé et affiché sur chaque base.

Peut-il convertir des valeurs fractionnaires ?

Non. Le convertisseur fonctionne uniquement sur des nombres entiers, ce qui couvre les cas importants pour les indicateurs binaires, les adresses et les valeurs de couleur.
