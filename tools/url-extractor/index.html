About the URL Extractor

The URL Extractor pulls every http and https link out of a block of text and lists them one per line. It is the fast way to collect links from a long email, a pasted document, a changelog or a chunk of HTML without clicking through them one at a time. Extraction stops at characters that cannot legally appear in a URL, such as whitespace, quotes and angle brackets, which is what keeps the results clean on messy input.

Where people use the URL Extractor

  • Collecting all the links from a long email or briefing document.
  • Extracting URLs from a block of HTML or a sitemap fragment.
  • Gathering download links listed in a changelog.
  • Checking which links appear in a page before migrating it.

How to use the URL Extractor

  1. 1

    Paste the text

    Any block of text works: an email body, a document, a log, or even raw HTML.

  2. 2

    Extract

    Every link is listed on its own line, in the order it appeared.

  3. 3

    Copy the list

    The result is plain text, one URL per line, ready to paste into a spreadsheet or a download manager.

  4. 4

    Watch for trailing punctuation

    A URL at the end of a sentence can pick up the full stop. Glance over the list before using it.

Tips and best practices

  • Run the result through Duplicate Line Remover if you want the unique set.
  • Watch for a trailing full stop when a URL ends a sentence.
  • Bare domains without http:// will not be found; add the scheme first.

Frequently asked questions

Why are some links missing?

Because they have no scheme. The extraction looks for http:// or https://, so a bare address such as example.com or www.example.com is not matched. Add the scheme, or search for the domain separately.

Why does a link end with a full stop or a bracket?

Because the extractor stops only at characters that are illegal in a URL, and a full stop is legal. Trailing punctuation at the end of a sentence is therefore captured. Trim it, or wrap URLs in angle brackets when you write them.

Does it follow redirects or check whether links work?

No. It only finds the text of the links. Checking whether they resolve needs a separate request to each one.

Does it remove duplicates?

No, every occurrence is listed. If you want the unique set, run the list through the Duplicate Line Remover.

Is the text uploaded?

No. The search happens in your browser, so pasted emails and internal documents never leave your device.
