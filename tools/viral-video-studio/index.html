About the Viral Video Script Studio

Viral Video Studio is a short-video script workshop that runs entirely in your browser with no AI and no accounts. It matches your topic to a content track, generates hook lines, a shot-by-shot storyboard and caption copy from built-in templates, and previews the result in a vertical 9:16 frame you can export as a cover image.

Everything is template-driven and deterministic: the same inputs give the same script, which makes it useful as a starting skeleton you then rewrite in your own voice. Nothing you type is uploaded.

It is built on the open-source Viral Video Studio (MIT License) and embedded here so the workshop runs without leaving Toolbox Hub. The interface is in Chinese, reflecting the short-video ecosystem it was built for.

Where people use the Viral Video Script Studio

  • Breaking a blank page when planning a short video.
  • Structuring a hook-storyboard-caption skeleton fast.
  • Exporting a vertical cover image for a post.

Frequently asked questions

Does it use AI?

No. It is entirely template-based, which is why it is instant, free and works offline. Treat the output as a structured draft, not finished copy.

Why is the interface in Chinese?

The upstream open-source project was built for the Chinese short-video ecosystem (Douyin, Kuaishou, Xiaohongshu). We kept the original interface to respect its design.

Is my input uploaded?

No. Everything runs locally in your browser.

Can I use the output commercially?

Yes. The output is yours; the tool adds no watermark and claims no rights.
