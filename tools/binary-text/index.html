Binary to Text

Binary text conversion

Binary text conversion Runs locally in your browser

Input made only of 0, 1 and spaces is decoded. Anything else is encoded.

About the

The Binary to Text converter translates text into binary and binary back into text, choosing the direction from what you paste: input made only of ones, zeros and spaces is decoded, anything else is encoded. Each character becomes one byte, shown as eight binary digits, and groups are separated by spaces so you can see where one character ends and the next begins. The eight-bit form is the one that matches how text is actually stored, and it is why you will see a leading zero at the start of every ordinary letter.

Where people use the

  • Learning how characters are represented as bytes.
  • Decoding a binary string from a puzzle or an exercise.
  • Checking what a byte value means without opening a calculator.
  • Demonstrating why text encodings need a defined character set.

How to use the

  1. 1

    Paste text or binary

    Anything containing only 1, 0 and spaces is decoded; everything else is encoded.

  2. 2

    Convert

    Encoded output is one eight-digit group per character, separated by spaces.

  3. 3

    Decode by pasting the groups

    Keep the spaces between groups. Without them the string cannot be split into bytes and the conversion will fail.

  4. 4

    Check for characters outside the range

    Values above 127 depend on how the text was encoded in the first place, so accented characters and emoji may not survive a round trip.

Tips and best practices

  • Keep one space between each eight-bit group when decoding.
  • For long data, use hexadecimal; it is four times shorter and far easier to read.
  • If a decode produces nonsense, check that no group has more than eight digits.

Frequently asked questions

Why eight digits per character?

Because one byte is eight bits, and a single byte is the unit most text encodings are built on. That is why the letter A, which is 65, is written 01000001.

Why does every letter start with 0?

Because standard ASCII values run from 0 to 127, and 127 in binary is 01111111. The top bit stays zero, so every ASCII character has a leading 0 in its eight-bit form.

Does it handle UTF-8 characters?

Partly. Encoding goes character by character using the Unicode code point, so characters above 255 produce groups longer than eight bits. Decoding expects byte-sized groups. For accented text and emoji the conversion may not round-trip cleanly.

How do I read a byte by hand?

Add the place values of the positions holding a 1, from left to right: 128, 64, 32, 16, 8, 4, 2, 1. So 01000001 is 64 plus 1, which is 65, the code for A.

Is this the same as hexadecimal?

No, but they represent the same underlying numbers. Hexadecimal is a more compact way to write the same bytes, which is why long binary strings are usually shown as hex instead.
