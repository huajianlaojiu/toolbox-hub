Hex text conversion All processing happens in your browser.

About the Hex to Text

The Hex to Text converter turns a string of hexadecimal byte values into the characters they represent, and it detects the direction for you: input made only of hex digits and spaces is decoded, anything else is encoded. That makes it one field you can paste into either way, which is what you want when you are reading a packet capture, debugging an encoding bug or checking what a binary field actually contains. Each byte is handled separately, so the conversion is exact rather than approximate.

Where people use the Hex to Text

  • Reading the text inside a packet capture or a hex dump.
  • Checking what a binary field in a database actually contains.
  • Debugging a mojibake bug by looking at the raw bytes.
  • Building a byte sequence to paste into a test fixture.

How to use the Hex to Text

  1. 1

    Paste a value

    Either hex bytes separated by spaces, such as 48 65 6c 6c 6f, or plain text you want encoded.

  2. 2

    Run it

    Input that is only hex digits and spaces is decoded to text. Anything else is encoded into hex.

  3. 3

    Check the direction

    If the output looks wrong, the input probably matched the other pattern. Remove the spaces to force encoding, or add them to force decoding.

  4. 4

    Copy the result

    The output is plain text, ready to paste back into your editor or terminal.

Tips and best practices

  • Separate bytes with spaces when decoding; without them the value is read as one number.
  • Values above 127 are not ASCII; expect non-text results.
  • Use the Number Base Converter if you want hex as a number rather than as text.

Frequently asked questions

How does it decide which way to convert?

It tests whether the input is made up only of hexadecimal digits and whitespace. If it is, the input is decoded. If not, it is encoded.

Why did my text come out as gibberish?

Because the bytes are not text in the encoding you expect. Values above 127 are interpreted as Unicode code points, which only match UTF-8 output by coincidence.

Do I need spaces between the bytes?

For decoding, yes. Spaces mark where one byte ends and the next begins. Without them the whole string is read as one number.

Is this the same as a hex to decimal converter?

No. This converts between hex and the characters those bytes represent. Use the Number Base Converter for hex to decimal.

Is the data uploaded?

No. The conversion happens in your browser, so packet captures and payloads stay on your device.
