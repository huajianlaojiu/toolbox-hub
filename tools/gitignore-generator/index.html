About the Gitignore Generator

Build a .gitignore by picking templates for languages, frameworks, editors, and operating systems. Search for Node, Python, macOS, or any other name in the list, select the ones that match the repo, and the page concatenates them in catalog order with a header for each template.

The templates follow the GitHub gitignore collection. Copy the result or download it as .gitignore. Generating the file does not need a network call after the page has loaded.

Where people use the Gitignore Generator

  • Starting a Node or Python repo without hand-writing ignore rules.
  • Adding macOS and editor junk rules to a project that already ignores build output.
  • Checking which paths a known template excludes before you commit them.

How to use the Gitignore Generator

  1. 1

    Search the catalog

    Type a language, framework, editor, or OS. The list filters as you type.

  2. 2

    Select templates

    Turn on each stack you use. The count above the list tracks the selection.

  3. 3

    Read the preview

    The combined file appears on the right, with a comment naming each template.

  4. 4

    Copy or download

    Copy it into a repo, or download a file named .gitignore.

Tips and best practices

  • Order is stable: the same selection always produces the same file.
  • A template is a starting point. Secrets and local paths that are unique to your repo still belong in the file by hand.
