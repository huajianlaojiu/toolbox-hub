About the Mermaid Diagram Editor

Write a Mermaid diagram and see it render beside the source. The examples cover a flowchart, a sequence diagram, a class diagram, an ER diagram, a Gantt chart, and a pie chart, and you can replace the sample with your own syntax. When the diagram is valid, download it as SVG or PNG.

The Mermaid library loads when you open the tool and renders in the browser. A syntax error is shown in place of the picture, so you can fix the line and render again. SVG stays sharp when you drop it into a document.

Where people use the Mermaid Diagram Editor

  • Drafting a flowchart for a README without opening a drawing app.
  • Checking a sequence diagram before you commit the Mermaid block.
  • Exporting an ER sketch as SVG for a design doc.

How to use the Mermaid Diagram Editor

  1. 1

    Start from an example or paste your own

    The flowchart sample is loaded first. Switch examples if you want a different diagram type.

  2. 2

    Edit the source

    The preview updates after you pause typing. A syntax error replaces the picture until the source parses.

  3. 3

    Download SVG or PNG

    SVG is the better default for docs. PNG is easier to drop into a slide that does not accept SVG.

Tips and best practices

  • Keep node IDs short and put the readable name in the label. That makes the source easier to diff.
  • If the picture is blank, read the error first. A missing arrow or an unclosed quote is the usual cause.

Frequently asked questions

What if the diagram is blank?

Read the error in place of the picture. A missing arrow or an unclosed quote is the usual cause. The preview returns when the source parses.

Is the source uploaded?

No. The Mermaid library loads with the tool and renders in this browser.

SVG or PNG?

SVG stays sharp in a document. PNG is the easier file for a slide that does not accept SVG.
