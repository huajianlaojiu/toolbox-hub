About the Compress PDF

Compress PDF is for a file that is large because of its pictures: a photo essay, a scan of ordinary JPEG pages, or a report you need to email. It recompresses the images embedded in the PDF. Regular keeps those pictures closer to the original. Strong uses a lower JPEG quality and a smaller maximum edge, so the pictures get softer. You see the original size, the new size, and the percentage saved before you rely on the download. The work happens in this browser. The file is not uploaded, and no account is required.

A text-only PDF often barely shrinks, because there are no pictures to recompress. Fax images, JPEG 2000, and some CMYK pictures are left as they are when the browser cannot decode them. The tool does not subset fonts or rebuild content streams. If the rewritten file is not smaller, the download is the file you started with.

Where people use the Compress PDF

  • Shrinking a photo-heavy PDF before emailing it.
  • Checking whether a report is mostly text and will not get much smaller.
  • Making a scan of ordinary JPEG pages lighter without sending it to a server.

How to use the Compress PDF

  1. 1

    Choose a PDF

    Drop one PDF. The original size is shown next to the file name.

  2. 2

    Pick Regular or Strong

    Regular keeps pictures closer to the original. Strong uses a lower JPEG quality and a smaller maximum edge.

  3. 3

    Compress

    The page reports the new size and the percentage saved, then downloads the PDF.

Tips and best practices

  • Try Regular first. Use Strong when the file still needs to be smaller and softer pictures are acceptable.
  • If the savings are tiny, the pictures were probably already compressed. Keeping the original is the right outcome.

Frequently asked questions

Will every PDF get smaller?

No. Text-only files and pictures that are already compressed often stay about the same size. The page says so when the savings are under 5 percent.

Is this as small as a desktop compressor?

Not always. This tool recompresses embedded images. It does not subset fonts or rebuild content streams the way a server-side compressor can.

Does the text stay selectable?

Yes, when the original had a text layer. The tool does not flatten pages into pictures. It only replaces embedded images it can decode.

Is the file uploaded?

No. Compression runs in your browser. A very large PDF can still run out of memory, especially on a phone.
