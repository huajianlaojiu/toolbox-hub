About the Add Subtitles

Add Subtitles burns captions into the picture and downloads an MP4. You provide a video plus an SRT, VTT, ASS, SSA, or SBV file. The preview shows roughly when each line appears, with the size, color, and position you picked. The export is not a sidecar subtitle file.

The download uses the bundled Noto Sans font. Latin, common accented European letters, Greek, and Cyrillic are covered. Chinese, Japanese, Korean, Arabic, Hebrew, Thai, and emoji are not in that font. The preview can still show those characters with a font on your device, and they can be missing or drawn as boxes in the MP4. The page lists the characters it cannot draw.

Nothing is uploaded. The first run downloads the ffmpeg engine, about 25 MB. A long video can be slow, and a phone may run out of memory. Styling is one size, one color, and top, center, or bottom. It will not match a professional captioning suite. Subtitle Editor still only edits the text file.

Where people use the Add Subtitles

  • Hardcoding English captions onto a short clip.
  • Burning a VTT file when a player will not load a sidecar.
  • Checking that a cue lands near the right moment before you export.

How to use the Add Subtitles

  1. 1

    Add a video and a subtitle file

    SRT, VTT, ASS, SSA, and SBV are read in the browser. The cue count is shown when the file parses.

  2. 2

    Set size, color, and position

    Bottom, center, or top. Play the preview to see roughly when each line appears.

  3. 3

    Read the font warning

    If the file contains characters outside Noto Sans, the page lists them before you export.

  4. 4

    Burn and download

    Keep the tab open. The result is an MP4 with the words drawn into the frames.

Tips and best practices

  • Edit timing in Subtitle Editor first if the cues are early or late.
  • White text at the bottom is the most readable default.

Frequently asked questions

Is this the subtitle editor?

No. Subtitle Editor changes the SRT, VTT, or ASS file. This page burns those cues into the video.

Will Chinese or Arabic show up in the MP4?

Not reliably. The bundled font does not include those scripts. The preview may still show them from your device, and the export can miss them.

Is the video uploaded?

No. ffmpeg runs in this browser. The first run downloads the engine, about 25 MB.

Can a phone burn a long video?

Sometimes. Large or long videos can be slow or run out of memory. A short clip on a desktop is the comfortable case.
