About the List Randomizer

The List Randomizer shuffles a list into a random order using an unbiased shuffle, so every item has the same chance of landing in any position. One item per line, and the result is the same list in a new order rather than a selection, which makes it useful for drawing a running order, assigning review duties or picking teams. Because the shuffle is random, running it again gives a different order.

Where people use the List Randomizer

  • Drawing a speaking or presentation order.
  • Assigning code review duties across a team.
  • Splitting a group into teams at random.
  • Picking a winner from a shortlist.

How to use the List Randomizer

  1. 1

    Enter your list

    One item per line. Blank lines are dropped before shuffling.

  2. 2

    Randomize

    The items are shuffled and returned in their new order, one per line.

  3. 3

    Take what you need

    If you only need one name, take the first line. If you need a running order, use the whole list.

  4. 4

    Run again for a different order

    Each run is independent, so a new shuffle is produced every time.

Tips and best practices

  • Take the first line when you just need one pick.
  • Remove duplicates first if each entry should appear once.
  • Run it again if you want a different order; each run is independent.

Frequently asked questions

Is the shuffle fair?

Yes. It uses a standard unbiased shuffle, so every ordering is equally likely. That is not true of the naive approach of sorting by a random number.

Can it pick just one item?

It shuffles the whole list, but the first line of the result is a fair single pick.

Does it remove duplicates?

No. Every line is kept, including repeated entries. Remove duplicates first if each entry should appear once.

Can the same order come up twice?

Yes, by chance. With more than a handful of items the odds are small, but it is possible.

Is randomness good enough for a prize draw?

For an informal draw, yes. For anything with real money or legal weight, use a cryptographically secure generator and record the process.
