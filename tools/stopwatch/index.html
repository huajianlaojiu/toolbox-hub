About the Online Stopwatch

The Online Stopwatch times an interval to a hundredth of a second, with start, pause, reset and lap controls. The lap button records a split without stopping the clock and shows both the cumulative time and the gap since the previous lap, which is what makes it useful for timing repeated efforts rather than one long interval. It runs in the page, so closing the tab stops it; keep the tab open while you time.

Where people use the Online Stopwatch

  • Timing laps or intervals during a training session.
  • Measuring how long a repeated manual task actually takes.
  • Timing a presentation or a demo run-through.
  • Checking page or process timings during a manual test.

How to use the Online Stopwatch

  1. 1

    Start

    Press Start to begin. The display shows minutes, seconds and hundredths.

  2. 2

    Pause when you need to

    Pause freezes the display and the counter. Start resumes from where it stopped rather than resetting.

  3. 3

    Record a lap

    Press Lap while running to record a split. Each lap shows its cumulative time and the difference from the previous one.

  4. 4

    Reset for a new run

    Reset returns the clock to zero and clears the lap list.

Tips and best practices

  • Keep the tab in the foreground; background tabs are throttled and can drift.
  • Use Lap rather than pausing when you want a running total to continue.
  • Reset before each new run so the lap list starts clean.

Frequently asked questions

How precise is it?

It displays hundredths of a second. The underlying timer ticks every ten milliseconds, which is finer than a person can react, so the practical limit is your own reflex rather than the clock.

Does it keep running if I switch tabs?

Yes, but browsers throttle timers in background tabs, so a background stopwatch can drift. Keep the tab in the foreground for anything you care about.

What is the difference between lap and split?

Nothing here. Each lap shows when it was taken and how long since the previous one, which covers both readings.

Can it count down instead?

No. This is a stopwatch, not a timer. Use the Pomodoro Timer if you want a countdown.

Is anything recorded or uploaded?

No. The timing and the lap list live in the page only, and clearing them removes them.
