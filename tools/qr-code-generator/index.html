About the QR Code Generator

The QR Code Generator turns any text or URL into a scannable QR code that you can download as a PNG. The code is rendered locally in your browser and never uploaded, so you can encode private data such as a Wi-Fi password or a serial number. Pick a pixel size and a margin that suits where the code will be printed, since a code that is too small or has too little quiet zone is the most common reason a phone camera refuses to scan it.

Where people use the QR Code Generator

  • Printing a QR code on a poster, packaging, or a business card.
  • Sharing a Wi-Fi password without typing it character by character.
  • Linking to a menu, a ticket, or a product page from a printed sign.
  • Adding a scannable code to a conference badge or slide.

How to use the QR Code Generator

  1. 1

    Enter the content

    Type a URL, a message, a phone number, or any plain text.

  2. 2

    Choose the size

    Select 128, 256 or 512 pixels. Larger codes scan more reliably, especially when printed small.

  3. 3

    Generate and download

    Click Generate, then download the PNG and place it where your audience can scan it.

Frequently asked questions

Why will my phone not scan the code?

Usually the quiet zone is too small or the code is too dense. Keep a margin of at least four modules around the code, and do not shrink it below about 2 cm in printed size.

Is there a scan limit on the number of characters?

A standard QR code holds up to roughly 4,296 alphanumeric characters or 2,954 numeric digits. Very long URLs may need a higher error correction level, which makes the code denser.

Can I create a QR code for a Wi-Fi network?

Yes. Enter the text in the form wifiname:WIFI;T:WPA;S:network;P:password;; and scanners will offer to join the network.
