About the Email Validator

The Email Validator checks a list of addresses for correct syntax and marks each one valid or invalid, handling several at a time separated by commas, spaces or new lines. It checks the shape of the address, not whether the mailbox exists, which is the honest limit of any client-side check. Use it to clean a mailing list before an import, or to catch typos in a signup form before they turn into bounces.

Where people use the Email Validator

  • Cleaning a mailing list before importing it into a campaign tool.
  • Checking a pasted list of signups for typos.
  • Validating test fixtures before a bulk import.
  • Finding the one bad row that is breaking an upload.

How to use the Email Validator

  1. 1

    Paste the addresses

    One per line, or separated by commas or spaces. Any number of addresses can be checked at once.

  2. 2

    Run the check

    Each address is listed with VALID or INVALID next to it, in the order you entered them.

  3. 3

    Look at the failures

    A missing @, a missing dot in the domain, a space inside the address or a trailing comma are the usual causes.

  4. 4

    Clean and re-run

    Fix the failures and run again to confirm the list is clean.

Tips and best practices

  • Syntax is not existence; a valid address can still bounce.
  • Separate addresses with new lines rather than commas when they come from a document.
  • Watch for a trailing comma on the last address of a list.

Frequently asked questions

Does this prove the address exists?

No. It checks syntax only. Proving a mailbox exists means sending mail or querying the mail server, which no browser tool can do.

Why is a valid-looking address marked invalid?

Usually a stray space, a comma left inside the address, or a missing top-level domain. The check requires an @, a domain, and a dot in the domain.

Does it accept addresses with plus signs or tags?

Yes. Anything before the @ that contains no whitespace or @ is accepted, so plus addressing passes.

Will it catch a typo in the domain?

Only if the typo breaks the syntax. gmial.com is syntactically valid and will pass, because there is no way to tell it apart from a real domain from the browser.

Is my list uploaded?

No. Checking happens in your browser, so customer lists never leave your device.
