About the ROT13 Encoder

The ROT13 Encoder shifts every letter thirteen places through the alphabet, which is the classic way to hide a spoiler, a puzzle answer or a punchline in plain sight. The trick is that thirteen is half of twenty-six, so the same operation both encodes and decodes: running the tool twice returns the original text. Only letters move; digits, punctuation and spacing are left alone.

Where people use the ROT13 Encoder

  • Hiding a spoiler or a puzzle answer in plain text.
  • Obfuscating a punchline that someone might read by accident.
  • Teaching how a simple substitution cipher works.
  • Making a string unreadable at a glance without any real security.

Frequently asked questions

Is ROT13 encryption?

No. It provides no security at all. Anyone can reverse it, which is the point when you are hiding a spoiler rather than protecting a secret.

Why does it work both ways?

Because there are twenty-six letters and the shift is thirteen. Shifting by thirteen twice is a shift of twenty-six, which is a full turn back to the start.

What happens to numbers and punctuation?

Nothing. Only the letters a to z and A to Z are shifted, and case is preserved.

Is it the same as a Caesar cipher?

It is one specific case of it, with a shift of thirteen. The Caesar Cipher tool lets you use any shift.

Does it handle accented letters?

No. Only the unaccented English alphabet is shifted; accented characters are passed through unchanged.
