About the Subtitle Editor

The Subtitle Editor loads, edits and converts subtitle files entirely in your browser. It reads SRT, VTT, ASS, SSA and SBV, shows every cue with editable timestamps and text, and writes back out in SRT, VTT or ASS with correct timecode formatting for each.

Load the matching video and the editor highlights the cue at the current playback position, so you can spot drift and fix timing against the picture. A one-click shift moves the whole track earlier or later when subtitles run consistently fast or slow.

Nothing is uploaded: parsing, editing and export all happen locally. It covers the everyday jobs — fixing an offset, tweaking a line, converting for a platform — without installing anything.

Where people use the Subtitle Editor

  • Fixing a constant offset in a downloaded subtitle file.
  • Converting SRT to ASS for styled subtitles.
  • Correcting a typo or a timing drift against the video.

How to use the Subtitle Editor

  1. 1

    Import a subtitle file

    Drop in SRT, VTT, ASS, SSA or SBV. Every cue is parsed into an editable list.

  2. 2

    Edit cues

    Click a cue to edit its text and timestamps. Delete cues you do not need, or add new ones.

  3. 3

    Fix timing

    Load the video for sync preview, or shift the whole track by a fixed offset in seconds.

  4. 4

    Export

    Download as SRT, VTT or ASS with correctly formatted timecodes.

Tips and best practices

  • Shift in small increments and preview against the video each time.
  • Export ASS when you need styling; SRT when you need compatibility.

Frequently asked questions

Which formats can it convert between?

It reads SRT, VTT, ASS, SSA and SBV, and writes SRT, VTT and ASS. That covers every platform you are likely to publish to.

How do I fix subtitles that are consistently early or late?

Enter the offset in seconds (negative for earlier) and click Shift all. Positive values push the track later.

Can it burn subtitles into video?

No, this is a text editor only. Export the fixed subtitle file and burn it with a video tool.

Is my file uploaded?

No. The file is read with the browser's file reader and never leaves your device.

Import a subtitle file to start editing. Everything stays in your browser.
