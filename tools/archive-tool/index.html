About the ZIP and TAR Archive Tool

Create a ZIP or a TAR from files on your computer, or open a ZIP or TAR and download what is inside. The create tab lets you pick the format before you pack the files. The extract tab reads the archive and lists the entries so you can save them.

ZIP is handled by JSZip. TAR is read and written in the page. 7z and RAR are not supported, because those formats need a different decoder. Nothing is uploaded: the archive is built or unpacked in the browser.

Where people use the ZIP and TAR Archive Tool

  • Bundling a few files into a ZIP without installing an archiver.
  • Checking what is inside a TAR before you unpack it elsewhere.
  • Pulling one file out of a ZIP.

How to use the ZIP and TAR Archive Tool

  1. 1

    Choose create or extract

    Create packs files you select. Extract opens an archive you already have.

  2. 2

    Add the files

    For a new archive, drop the files and choose ZIP or TAR. For an existing archive, drop the ZIP or TAR.

  3. 3

    Run it

    Create downloads the archive. Extract lists the entries inside.

  4. 4

    Save what you need

    Download individual extracted files, or the new archive, from the page.

Tips and best practices

  • If an archive will not open, check the extension. 7z and RAR need a different tool.
  • TAR here is an uncompressed archive. A .tar.gz still needs to be gunzipped first.

For most tools, no — the computation runs in your browser and your input is not sent to a server we operate. Some tools download a processing engine or language model from a third-party CDN on first use. See the privacy policy for the full list of third-party services.

Does it work on a phone or tablet?

Yes. The layout is responsive and adapts to phones, tablets and desktops. On a small screen the controls stack vertically so the input stays readable.

Do I need to create an account?

No. There is no registration, no email confirmation and no login. Bookmark the page instead, and it will behave like any other utility you use daily.

Yes. The output is yours to use in client work, products and publications. There is no attribution requirement and no restriction on commercial use.

How accurate is the result?

The tool applies a deterministic rule rather than an estimate, so repeated runs on the same input always give the same output. For anything legally or financially consequential, double-check against your own source of truth.
