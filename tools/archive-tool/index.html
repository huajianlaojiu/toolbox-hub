Create and extract ZIP TAR archives in your browser

Create and extract ZIP TAR archives in your browser Runs locally in your browser

Format

ZIP handled by JSZip; TAR read/written with a built-in encoder. 7Z / RAR need native engines and are not supported. Everything stays in your browser.

About the

Archive Tool is a free browser-based tool on Toolbox Hub. Create and extract ZIP TAR archives in your browser. It exists to remove a small but annoying task from your workflow: instead of installing an app, writing a script, or hunting through a settings panel, you open one page and get the answer.

Everything runs locally in your browser using JavaScript. Nothing you type is uploaded to a server, no account is required, and the tool keeps working on a slow or intermittent connection. That makes it equally useful for a quick one-off check and for repeated daily use.

Typical uses include checking a value before sending it to a client, converting a batch of numbers for a spreadsheet, cleaning up text before pasting it into a ticket, or verifying a result produced by a script. If you keep landing on this page for the same task, bookmark it.

Frequently asked questions

Is this Archive Tool free to use?

Yes. It is completely free, with no sign-up, no trial period, no usage limit and no watermark. There is also no paid tier that holds back basic functionality.

Is my data uploaded to a server?

No. The tool runs entirely in your browser, so your input never leaves your device. This is also why there is no file size limit and why the tool still works offline once the page has loaded.

Does it work on a phone or tablet?

Yes. The layout is responsive and adapts to phones, tablets and desktops. On a small screen the controls stack vertically so the input stays readable.

Do I need to create an account?

No. There is no registration, no email confirmation and no login. Bookmark the page instead, and it will behave like any other utility you use daily.

Can I use it for commercial work?

Yes. The output is yours to use in client work, products and publications. There is no attribution requirement and no restriction on commercial use.

How accurate is the result?

The tool applies a deterministic rule rather than an estimate, so repeated runs on the same input always give the same output. For anything legally or financially consequential, double-check against your own source of truth.
