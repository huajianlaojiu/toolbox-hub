About the XML Formatter

The XML Formatter re-indents an XML document so its structure is visible, adding a line break and two spaces per level around every tag. It is the quickest way to read an XML response from a SOAP endpoint, an Android manifest or a config file that arrives as one long line. The formatter rearranges whitespace only; it does not validate the document or check it against a schema, so a malformed document will still come out indented.

Where people use the XML Formatter

  • Reading a single-line XML response from a SOAP or legacy endpoint.
  • Cleaning up an Android manifest or a Maven config before a review.
  • Comparing two XML documents in a diff after re-indenting both.
  • Checking the nesting of a document you generated.

How to use the XML Formatter

  1. 1

    Paste the XML

    Drop the document in straight from a response, a log or an editor. Whitespace between tags is discarded before formatting.

  2. 2

    Format it

    Each tag is placed on its own line and indented by two spaces per nesting level.

  3. 3

    Read the structure

    Closing tags line up with their opening tags, which is what makes a deep document readable.

  4. 4

    Copy it back

    The result is plain text, ready to paste into your editor or a diff tool.

Tips and best practices

  • Format before you diff; two documents with different whitespace look different otherwise.
  • Formatting is not validation; check the document separately if it must be correct.
  • Attributes are left untouched, so long attribute lists stay on one line.

Frequently asked questions

Does it validate the XML?

No. It only re-indents. A document with a mismatched tag will still be formatted, so run it through a validator if correctness matters.

Does it change my content?

No. Only whitespace between tags is altered. Element names, attributes and text content are left exactly as they were.

What about self-closing tags and comments?

Self-closing tags are placed on one line and do not increase the indent. Comments and processing instructions are treated as ordinary tokens.

Can it minify instead?

No. This tool only expands a document. To collapse it, remove the line breaks yourself or use a dedicated minifier.

Is the document uploaded?

No. Formatting happens in your browser, so internal config and response payloads stay on your device.
