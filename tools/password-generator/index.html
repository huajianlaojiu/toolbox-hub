About the Password Generator

The Password Generator creates strong random passwords using your browser's cryptographic random number generator, not Math.random. You control the length, and you decide whether to include lowercase letters, uppercase letters, digits and symbols. Because generation happens locally, the password is never transmitted, logged or stored anywhere, which is exactly how a password should be handled.

Where people use the Password Generator

  • Creating a password for a new account when your usual one is already used.
  • Generating a separate strong password for your email account.
  • Producing a long passphrase you can actually remember and type.
  • Rotating a password after a service reports a breach.

How to use the Password Generator

  2. 2

Frequently asked questions

How long should a password be?

At least 12 characters for ordinary accounts, and 16 or more for email, banking and any account that protects other accounts.

Does this site store my generated password?

No. The password is created in your browser and never leaves your device. Clearing the tab destroys it.

Should I use a passphrase instead?

For long-term accounts you use daily, a multi-word passphrase is often better. It is far longer than a short random password and much easier to type.

Is a symbol-only password better?

Not by itself. Length matters more than character variety, so a long passphrase of letters usually outperforms a short string of symbols.
