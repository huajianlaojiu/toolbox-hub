Merge and Split PDF

Merge, split, images to PDF, and PDF to text or images

Runs locally in your browser

About the Merge and Split PDF

Merge several PDFs into one, split a PDF by page range, build a PDF from images, or export PDF pages as images and plain text. Pick the job from the tabs. Merge needs at least two PDFs and keeps their page order. Split accepts ranges such as 1-3, 5, 8-10, or a checkbox that writes every page as its own file.

PNG or JPG images become one PDF, with an optional maximum width so a camera photo does not land at full sensor size. PDF to images renders each page as a PNG. PDF to text reads the text layer, which is empty on a scan that was never OCR'd. The files stay on your device.

Where people use the Merge and Split PDF

  • Combining scanned chapters into a single PDF.
  • Pulling three pages out of a long report.
  • Making a PDF from a set of photos.

How to use the Merge and Split PDF

  1. 1

    Choose a tab

    Merge, Split, Images to PDF, PDF to Images, or PDF to Text.

  2. 2

    Add the files

    Merge wants two or more PDFs. The other tabs take one PDF, or a set of images.

  3. 3

    Set the options

    Split uses a page range unless you split every page. Images to PDF can cap the width.

  4. 4

    Download the result

    A merge, a page-range extract, or an image PDF downloads as one PDF. Splitting every page, and PDF to images, download as a zip. PDF to text also shows the text on the page.

Tips and best practices

  • A scanned PDF has no text layer, so PDF to Text will come back empty. Use the image-to-text tool on an exported page if you need OCR.
  • Put files in the order you want before merging. The tool follows the order you selected.

Frequently asked questions

Is this Merge and Split PDF free to use?

Yes for a typical single use. There is no account and no watermark. An optional Pro plan raises batch limits, lets you export the job list saved in this browser, and removes ads. A one-at-a-time job is not held back by the paid plan.

Is my data uploaded to a server?

For most tools, no — the computation runs in your browser and your input is not sent to a server we operate. Some tools download a processing engine or language model from a third-party CDN on first use. See the privacy policy for the full list of third-party services.

Does it work on a phone or tablet?

Yes. The layout is responsive and adapts to phones, tablets and desktops. On a small screen the controls stack vertically so the input stays readable.

Do I need to create an account?

No. There is no registration, no email confirmation and no login. Bookmark the page instead, and it will behave like any other utility you use daily.

Can I use it for commercial work?

Yes. The output is yours to use in client work, products and publications. There is no attribution requirement and no restriction on commercial use.

How accurate is the result?

The tool applies a deterministic rule rather than an estimate, so repeated runs on the same input always give the same output. For anything legally or financially consequential, double-check against your own source of truth.
