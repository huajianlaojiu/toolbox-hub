About the Timestamp Converter

The Timestamp Converter translates between Unix timestamps and human-readable dates in both directions. It covers seconds, milliseconds and microseconds, and it reads dates in local time, UTC or a fixed offset. This is the tool to reach for when a log line contains 1712345678 and you need to know when that actually happened, or when a database column stores a datetime and a script needs a raw epoch value.

Where people use the Timestamp Converter

  • Reading a timestamp from a server log and understanding when it happened.
  • Converting a stored date into an epoch value for a database query.
  • Checking whether a timestamp came from a UTC or local clock.
  • Converting an API expiry field into a human-readable date.

How to use the Timestamp Converter

  1. 1

    Paste a timestamp or a date

    Enter a 10-digit epoch value, a millisecond value, or a date string such as 2024-05-01 12:30:00.

  2. 2

    Pick the timezone

    Switch between your local timezone and UTC. The difference matters when you are reading a server log written in UTC.

  3. 3

    Copy the value

    Copy the formatted date for a report, or the epoch value for your code.

Frequently asked questions

Is a Unix timestamp in seconds or milliseconds?

Seconds. A 10-digit value is seconds, a 13-digit value is milliseconds. The tool detects this automatically.

Why is my timestamp off by eight hours?

You are probably comparing a UTC log entry with a local time. Check which timezone the server writes in before assuming the timestamp is wrong.

Does it handle the year 2038 problem?

Yes. The tool handles timestamps well beyond 2038, so it will not overflow the way a 32-bit signed integer does.
