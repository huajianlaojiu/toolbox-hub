About the Meta Tag Generator

The Meta Tag Generator builds the head tags a page needs for search and sharing: a title, a description, and the matching Open Graph tags. It emits both the plain meta description used by search results and the og equivalents used when a link is shared, so the same text does not have to be written twice. Paste in a title and a description and copy the block straight into your head element.

Where people use the Meta Tag Generator

  • Generating the head block for a new page.
  • Adding sharing tags to a page that only has a title.
  • Producing a consistent starting block across a set of pages.
  • Checking what a page's tags should look like before handing them to a developer.

How to use the Meta Tag Generator

  1. 1

  2. 2

    Treat the output as a starting point. A description written for a specific page will always beat a generic one.

Tips and best practices

  • Keep the description near 155 characters so it is not truncated.
  • Write a distinct description per page; duplicated ones are ignored in practice.
  • Avoid double quotes in the text, or escape them before pasting.

Frequently asked questions

Why both a meta description and og:description?

They are read by different systems. Search engines use the meta description for result snippets, while social platforms use the og tags for link previews. They can be the same text or different.

Does a meta description affect ranking?

Not directly. It does affect how often people click your result, which is why it is worth writing properly rather than leaving empty.

How long should the description be?

Around 150 to 160 characters. Longer text is truncated in search results, so put the important part first.

Is that all a page needs?

No. A canonical tag, a robots directive and og:image are usually wanted as well. This tool covers the two text fields, not the whole head.

Does it escape quotes in my text?

No. If your description contains a double quote, replace it with a single quote or escape it before pasting, or the attribute will break.
