17 Free Text Tools for Writers, Students and Marketers

Clean up copy, count words accurately, format lists and turn rough drafts into something publishable — with free browser tools that never upload your text.

Writing for work involves a surprising amount of mechanical drudgery that has nothing to do with writing: stripping stray whitespace from a pasted paragraph, checking a word limit, de-duplicating a list of names, converting something into a URL slug.

These seventeen tools are for that part of the job. They all run locally in the browser, which is not a small detail — the draft you paste is often unpublished, and the list you are sorting is often somebody's personal data.

Measuring what you have written

Word count sounds solved until a client asks for exactly 800 words and your editor says 820, or a form rejects your text at 1,995 characters with no explanation of where the newline went.

  • Word Counter — the standard measure. Paste, read, adjust.
  • Letter Counter — counts characters and letter frequency. Useful when you are debugging why one paragraph feels wrong: it is usually a repeated letter pattern, not a dream.

A note on what "a word" means: different counters disagree on hyphenation, numbers and URLs. If an exact number matters, use the same counter the person checking your work uses, and agree on it in advance. This is a genuinely common source of small, pointless arguments.

Cleaning up copy you did not write

Most text you receive is slightly damaged: double spaces from a copy-paste, a stray tab, inconsistent capitalisation from someone typing in a hurry. Fixing it by hand is slow and error-prone.

  • Text Trimmer — remove leading and trailing whitespace from every line at once. This fixes more "formatting looks broken" reports than anything else on this list.
  • Text Case Converter — switch between sentence case, title case, upper and lower across a block. Also the fastest way to undo an accidental CAPS LOCK paragraph.
  • Text to Slug — turn a headline into a clean URL slug. Paste your title, get the slug, done.

The slug generator has one use beyond URLs: it is a fast way to make a readable filename or anchor that a human can parse at a glance, which beats `final_final_v3`.

Working with lists

Listicles, inventories, mail merges, tag cleanups, survey responses, spreadsheet columns — at some point everything becomes a list and every list needs sorting, de-duplicating or randomising.

  • Duplicate Line Remover — compare two lists, or clean one. The output tells you how many duplicates were removed, which is useful when you are reporting the result.
  • List Sorter — the same job for structured list input.
  • List Randomizer — shuffle a draw order, a quiz sequence or a ring-fenced shortlist so nobody suspects favouritism.
  • Line Number Adder — number lines for reference in a ticket or a code review comment.

The classic trap here is a list that looks de-duplicated but is not: `Apple`, `apple ` and `Apple.` are three different lines to a computer. Trim whitespace and strip trailing punctuation before you dedupe, or you will merge nothing and conclude the data is clean.

Previewing and formatting

Markdown has won, but not uniformly. Half your tools render it, half do not, and the half that does not is usually the one someone senior has to paste into.

  • Markdown Preview — live rendering, so you can check a table or a nested list actually looks right before it reaches a client.
  • Text Repeater — repeat a string N times. Useful for generating padding, test data or, occasionally, making a point in a document.

The Markdown preview is the tool that quietly saves the most time in this whole set, because a broken table in a rendered document is far more visible — and far more embarrassing — than a broken table in raw text.

The rest, and when to reach for them

  • Random String Generator — generate readable nonces, placeholder IDs or short codes. Better than inventing something by hand, because you will not accidentally reuse it.
  • Morse Code Translator — genuinely fun, occasionally useful for a themed project or a puzzle.

These are lower-frequency tools, but they cost nothing to keep bookmarked and they solve the specific problem of "I need a random-looking value right now and I do not trust myself to make one up".

A realistic editing pass

Here is the order that works when a draft arrives from someone else and needs to go out under your name.

  • 1. Trim. Run the whole document through the Text Trimmer first. Whitespace damage hides inside paragraphs where you will never see it.
  • 2. Clean case. Use the Text Case Converter for the headline only. Never apply case conversion to a full draft — it destroys proper nouns.
  • 3. Measure. Check length with the Word Counter before writing, so you know what shape the piece is meant to be.
  • 4. Preview. If it contains Markdown, render it with the Markdown Preview.
  • 5. Slug. Generate the URL slug last, from the final headline, with Text to Slug — changing the headline afterwards breaks the slug.

The whole pass takes a few minutes and eliminates the category of mistake where a document is technically correct and visibly wrong.

Writers' questions about privacy

Does my unpublished text leave my computer? No. These tools process text in your browser and nothing is stored or transmitted.

Is there a length limit? There is no server-side limit because there is no server call. Extremely large inputs are limited by your own device's memory.

Can I use the output commercially? Yes, freely, with no attribution.

Do they work on a phone? Yes. The layout adapts, and the same code runs.

What these tools will not do for you

Worth being blunt about the limits, because a tool that mechanises the wrong thing just produces a faster mistake.

None of these utilities can tell you whether a sentence is clear, whether a claim is sourced, or whether a tone is right for the audience. They count characters; they do not judge prose. A text that scores beautifully on every metric on this page can still be unreadable.

Nor do they edit. The moment you find yourself rewriting individual clauses by hand at scale, you have outgrown a text tool and you want either a proper editor, a find-and-replace with regex — which the Regex Tester is genuinely good for rehearsing — or a script. Use the browser for the mechanical layer, and keep your own judgement for everything above it.

One more thing they will not do is fix a bad source. If your spreadsheet is full of inconsistent naming — "Dr", "DR", "Dr." all in one column — a tool will sort and de-duplicate what you gave it faithfully, and you will still have three entries where there should be one. Cleaning the data is a decision, not a mechanical step. Decide the canonical form first, then apply it, then check.

Keeping a working list usable

If you maintain a list of leads, links, references or terms, it degrades quietly. The failure mode is always the same: entries that look identical are not, and one merge removes nothing.

A maintenance pass that works is boring: trim whitespace, standardise capitalisation, strip trailing punctuation, then de-duplicate. In that order — trimming after de-duplicating loses entries. Doing this once a month on an active list turns a two-hour unrecoverable mess into a ten-minute chore.

When two lists need reconciling — say, a registration list against an attendance list — sort both with the List Sorter first, so they line up, then compare by eye. Sorting both sides before comparing is the difference between a two-minute check and a twenty-minute hunt.

The takeaway

None of these tools is clever. That is the point: they remove the mechanical five percent of writing that is not writing, so the remaining ninety-five percent is actually about sentences. Bookmark the ones you use monthly, ignore the rest, and stop fixing whitespace by hand.
