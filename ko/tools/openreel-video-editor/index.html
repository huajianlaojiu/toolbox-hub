About the

OpenReel Video Editor is a full timeline editor that runs entirely in your browser — a genuine alternative to desktop editors and to CapCut. It gives you multi-track cutting, transitions, effects, colour grading, audio mixing, text and subtitle layers, and final export, all without uploading a single frame.

Editing happens through the browser's own WebCodecs pipeline and WebAssembly, so the heavy work stays on your machine. There is no account to create, no cloud render queue, and no watermark on the output.

It is built from the open-source OpenReel Video project (MIT License) and embedded here so you can edit without leaving Toolbox Hub. Because the editor is a complete application rather than a single-purpose tool, it takes a moment to load the first time.

Where people use the

  • Cutting a vertical short video without installing an editor.
  • Trimming and joining clips with transitions and background music.
  • Adding text, subtitles and colour grading to an existing clip.

How to use the

  1. 1

    Pick an aspect ratio

    Choose vertical (1080×1920), horizontal (1920×1080) or square (1080×1080) on the start screen.

  2. 2

    Import your clips

    Use the Media panel to import video, audio and images from your device. Nothing is uploaded.

  3. 3

    Edit on the timeline

    Drag clips onto tracks, trim them, add transitions, text, effects and adjust colour in the inspector.

  4. 4

    Preview and export

    Scrub the preview to check the cut, then use Export to render the final video.

Tips and best practices

  • Start from a preset aspect ratio so export matches your target platform.
  • Keep projects local: the editor autosaves to browser storage, so use one browser for an edit session.

Frequently asked questions

Is this a real editor or just a trimmer?

A real editor: multi-track timeline, transitions, effects, colour grading, audio mixing, text layers and export. It is built on the open-source OpenReel Video project.

Is my footage uploaded?

No. Decoding and rendering run locally through WebCodecs and WebAssembly. Your files never leave the device.

Does the export have a watermark?

No. The project is open source and free, and the export is clean.

Why is the first load slow?

The editor is a complete application — several megabytes of code and WebAssembly engines. After the first visit your browser caches it and later loads are much faster.

Which browsers are supported?

Recent Chrome, Edge and other Chromium browsers, which have the WebCodecs support the editor relies on. Safari support depends on its WebCodecs implementation.
