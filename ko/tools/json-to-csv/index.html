JSON to CSV

Convert JSON to CSV

Convert JSON to CSV Runs locally in your browser

Paste an array of objects. The keys of the first object become the CSV header row.

About the

The JSON to CSV converter turns an array of JSON objects into a CSV table, using the keys of the first object as the header row. It is the quickest way to get API data into a spreadsheet, since a CSV opens directly in Excel, Google Sheets or any analysis tool. Values are quoted according to CSV rules, so text containing commas survives the round trip.

Where people use the

  • Turning an API response into a spreadsheet for analysis.
  • Preparing a data import file from JSON records.
  • Sending a data extract to someone who works in Excel.
  • Spot-checking a set of records in a table rather than as text.

How to use the

  1. 1

    Paste a JSON array

    An array of objects, such as a list of records from an API. Each object becomes one row.

  2. 2

    Convert

    The keys of the first object become the header row, and each subsequent object becomes a row beneath it.

  3. 3

    Check the header

    Only the keys present on the first object are used. Records with extra keys will lose those fields.

  4. 4

    Copy and save

    Paste the result into a text editor and save it with a .csv extension, or paste it straight into a spreadsheet.

Tips and best practices

  • Flatten nested objects first; CSV has nowhere to put them.
  • Make sure the first record has every key you want as a column.
  • Save with a .csv extension and UTF-8 encoding if the data is not ASCII.

Frequently asked questions

Why does it say expected JSON array?

Because the top level is an object rather than a list. Wrap it in square brackets, or convert the object you actually need into an array first.

What happens to nested objects?

They are written as JSON text inside the cell, because CSV has no way to represent nesting. Flatten the structure first if you want one column per field.

What if records have different keys?

The header comes from the first record. Later records with different keys will have missing or empty cells rather than extra columns.

Are commas inside values handled?

Yes. Values are quoted following CSV rules, so a comma inside a value does not create an extra column.

Is my data uploaded?

No. Conversion happens in your browser, so exported customer data stays on your device.
