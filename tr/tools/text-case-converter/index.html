About the Text Case Converter

The Text Case Converter rewrites text as UPPERCASE, lowercase and Title Case in one pass, so you can compare the three and pick the one a style guide actually wants. The tricky one is Title Case: every style guide capitalises it differently. This tool applies the common rule, capitalising each word and lowercasing the rest, which means it will also capitalise short words such as and, of and the. If your house style keeps those lowercase, run the result through your own list of exceptions afterwards.

Where people use the Text Case Converter

  • Converting a list of headings into the casing a style guide requires.
  • Turning SHOUTING text from a legacy system into something readable.
  • Normalising a batch of database values before importing them.
  • Preparing alt text or labels that need consistent capitalisation.

Tips and best practices

  • For SEO titles, sentence case reads better and avoids the exception list entirely.
  • Avoid ALL CAPS for anything longer than a few words; it measurably slows reading.
  • Convert before you insert text into a design tool, so you do not have to redo it per frame.

Frequently asked questions

Which Title Case rule is used?

The simple rule: capitalise the first letter of every word and lowercase the rest. That matches neither AP nor Chicago exactly, because both keep short function words lowercase. Use SENTENCE CASE or correct the small words afterwards if you are publishing to a strict style guide.

Why did the word iPhone come out as Iphone?

Because capitalisation rules operate on letters, not brands. Any word with deliberate internal capitalisation, such as iPhone, eBay or monday.com, needs restoring by hand.

Does it handle accents and non-Latin scripts?

Latin letters with diacritics are handled by the browser's own case mapping. Scripts without case, such as Chinese, Japanese and Arabic, pass through unchanged, which is correct.

Can I convert only part of the text?

Paste only that part. The tool has no selection mode, so the input is treated as one block.

Is the text uploaded anywhere?

No. Case conversion uses the browser's own toUpperCase and toLowerCase, so the text never leaves your device.
