About the

The Decimal to Fraction converter turns a decimal into a fraction in its lowest terms, using the number of decimal places you typed as the starting denominator and then dividing out the common factor. It is the tool for turning 0.375 into three-eighths, or for checking a measurement against a fraction you are expected to use. Whole numbers are reported as themselves over one.

Where people use the

  • Converting a measurement into the fraction a plan or a recipe expects.
  • Checking a decimal against a known fraction.
  • Turning a ratio into whole numbers for a mix or a scale.
  • Simplifying a value for a report or a specification.

How to use the

  1. 1

    Enter a decimal

    Type a single decimal number, such as 0.375 or 2.5.

  2. 2

    Run it

    The equivalent fraction is shown in its lowest terms.

  3. 3

    Check the precision

    The denominator comes from the digits you typed, so 0.33 becomes thirty-three hundredths rather than a third.

  4. 4

    Round first if you meant a simpler fraction

    If the value is a rounded version of a common fraction, convert that fraction instead.

Tips and best practices

  • Type the full precision you have; fewer digits give a cruder fraction.
  • A repeating decimal needs to be entered to a finite number of places.
  • Values above one come out as improper fractions.

Frequently asked questions

Why is 0.33 not one third?

Because 0.33 is thirty-three hundredths, which is not the same as a third. The tool converts exactly what you typed, not the value you were rounding to.

Does it handle repeating decimals?

No. A repeating decimal has to be typed to a finite number of places, so the result is the fraction for that finite value.

What about a value greater than one?

It is converted to an improper fraction, so 2.5 becomes five halves. Converting to a mixed number is a separate step.

Are negative decimals handled?

Yes. The sign is carried through to the result.

Why is the result approximate?

Because the conversion rounds to the precision you typed. More decimal places give a closer fraction, usually with a larger denominator.
