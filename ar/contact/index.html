Contact Toolbox Hub

Bug reports, tool requests, corrections and partnership enquiries are all welcome. Every message is read by a human, and we reply to most of them within a few days.

Email

The fastest route is email: hello@toolbox-hub.io

Reporting a bug

Include the following so the issue can be reproduced and fixed:

  • The tool name and, if relevant, a link to its page.
  • Your browser and version, plus your operating system.
  • What you expected to happen, and what happened instead.
  • A sample input, if the input can be shared without exposing private information.

Requesting a tool

Requests are prioritised by how often people search for the missing capability and by how many existing tools it would connect to. A short note on the job you are trying to do is more useful than just a tool name, because it often reveals a better way to solve it.

Advertising and partnerships

For direct advertising enquiries, use the same address with the subject line prefixed "Advertising". For API access, white-label licensing or embedding the tools in another product, prefix the subject with "API".

Response time

Bug reports are usually investigated within a few working days. Tool requests are triaged weekly, and new tools ship in batches, so a request may take longer than a bug fix to appear.
