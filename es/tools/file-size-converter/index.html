About the

The File Size Converter translates between binary units such as bytes, kilobytes, megabytes, gigabytes and terabytes, and decimal units such as KB, MB, GB and TB. The difference is small but it matters: a file shown as 1 MB by an operating system is 1,048,576 bytes, while a vendor that advertises 1 GB of storage means 1,000,000,000 bytes. This tool shows both so you always know which one you are looking at.

Frequently asked questions

Is 1 MB 1000 KB or 1024 KB?

Both exist. Operating systems use 1024 (binary), while manufacturers use 1000 (decimal). That is why a 1 GB disk shows as 931 GB in Windows.

How many bytes are in a megabyte?

1 megabyte is 1,048,576 bytes in binary units, and 1,000,000 bytes in decimal units.

Why does my file look smaller than the label?

Because drive manufacturers use decimal units while the operating system reports binary units. The discrepancy is about 7 percent for a terabyte drive.
