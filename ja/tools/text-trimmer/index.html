Text Trimmer

Trim whitespace

Trim whitespace Runs locally in your browser

Trims each line, collapses runs of blank lines to one, and trims the ends.

About the

The Text Trimmer removes the whitespace you did not mean to keep: spaces at the start and end of every line, repeated blank lines, and whitespace around the whole block. It runs on each line independently, so a list pasted out of a document comes back clean without you touching it. This is the step to run before comparing two blocks of text, since invisible whitespace is the usual reason two identical-looking strings do not match.

Where people use the

  • Cleaning a list pasted out of a document or a spreadsheet.
  • Making two blocks of text comparable before a diff.
  • Removing stray indentation from a pasted code snippet.
  • Tidying up text before importing it into a system that is strict about whitespace.

How to use the

  1. 1

    Paste the text

    Any block works: a list, a code snippet, or text pasted out of a document.

  2. 2

    Run it

    Each line is trimmed, runs of blank lines collapse to one, and the whole block is trimmed at both ends.

  3. 3

    Check what changed

    Blank lines separating paragraphs are kept as single blank lines, so the structure survives.

  4. 4

    Copy the result

    Paste the cleaned text wherever it needs to go.

Tips and best practices

  • Run this before comparing two strings that look identical but do not match.
  • Paragraph breaks survive; only repeated blank lines are collapsed.
  • Indentation at the start of a line is removed, so do not run it on code where indentation matters.

Frequently asked questions

Does it remove blank lines entirely?

No. Runs of blank lines collapse to a single blank line, so paragraph breaks are preserved.

Does it trim inside lines?

No. Spaces between words are left alone. Only leading and trailing whitespace on each line is removed.

Does it remove tabs?

Yes, when they are at the start or end of a line. Tabs inside a line are kept, since they may be meaningful.

Why does my code still not match?

Because the difference is not whitespace, or it is indentation that is meaningful. This tool strips whitespace only; it does not change content.

Is my text uploaded?

No. Trimming happens in your browser, so pasted documents and code stay on your device.
