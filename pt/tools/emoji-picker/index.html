About the

The Emoji Picker holds a searchable set of emoji with keyword names, so you can type a word such as love, fire, coffee or warning and get the matches rather than scrolling. Clicking any emoji copies it to your clipboard, and the ones you have used stay in a recently copied row. Each emoji also carries a title, so hovering shows its official name, which is handy when you need the right word for alt text or a commit message.

Where people use the

  • Finding the right emoji for a commit message or a changelog entry.
  • Building a reaction bar or a survey scale.
  • Looking up an emoji's real name for alt text.
  • Checking which emoji exists before designing around it.

How to use the

  1. 1

    Type a keyword

    Search matches the name rather than the character, so love finds hearts, weather finds sun and rain, and food finds pizza and cake.

  2. 2

    Click to copy

    Clicking an emoji copies it immediately and adds it to the recently copied row. No need to select the character by hand.

  3. 3

    Copy the whole recent row at once

    The copy button above the recent row copies them all as one string, which is useful when you are building a reaction bar.

  4. 4

    Clear the search to browse

    Empty the search box and the full set comes back, grouped by the order it is stored in.

Tips and best practices

  • Search by concept rather than by appearance; the names are the searchable part.
  • Remember that rendering differs per platform, so never rely on one vendor's artwork.
  • Use sparingly in professional copy; one emoji carries more weight than five.

Frequently asked questions

How does the search work?

It matches against a keyword list attached to each emoji, not against the character itself. So searching face returns every face, and searching tick returns the check mark rather than a literal tick character.

Does clicking copy it?

Yes, to your clipboard using the browser's clipboard API. If your browser blocks clipboard access, the emoji still appears in the recent row so you can select it manually.

Why does an emoji look different on another device?

Because each platform ships its own emoji font. Apple, Google, Microsoft and Samsung all draw them differently, and an emoji added recently may not exist on older systems at all, where it shows as an empty box.

Is there a search for skin tone or gender variants?

No. This set uses the base characters. Skin tone modifiers and other variation sequences are separate code points that you would append yourself.

Can I use these commercially?

The emoji characters themselves are Unicode and free to use. The specific artwork belongs to each platform's font, so do not lift a vendor's images; use the characters and let the reader's own font render them.

Is anything uploaded?

No. The set is bundled in the page and the search runs locally, so it works offline once loaded.
