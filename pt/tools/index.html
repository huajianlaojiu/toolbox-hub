Como essas ferramentas são diferentes

Funciona no seu dispositivo

A maioria das conversões, formatos e cálculos acontecem na página, portanto sua entrada não é enviada para um servidor que operamos. Algumas ferramentas baixam um mecanismo de processamento de um CDN na primeira utilização; consulte a política de privacidade para obter detalhes.

No account required

There is no registration. A single job stays free. Larger batches, a downloadable history, and an ad-free page are optional on Pro.

Construído para um trabalho cada

Cada ferramenta possui uma única página com a entrada, o resultado e um botão de copiar. Sem painéis, sem configurações para configurar primeiro.

Procurando o raciocínio por trás de uma ferramenta, e não a ferramenta em si? O Toolbox Hub blog aborda como combiná-los para um trabalho real.
